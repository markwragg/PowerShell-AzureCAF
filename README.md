# PowerShell-AzureCAF

[![Build Status](https://dev.azure.com/markwragg/GitHub/_apis/build/status/markwragg.PowerShell-AzureCAF?branchName=main)](https://dev.azure.com/markwragg/GitHub/_build/latest?definitionId=XX&branchName=main) ![coverage](https://img.shields.io/badge/coverage-00%25-brightgreen.svg)

A PowerShell module for generating Azure Resource names per the Cloud Adoption Framework naming recommendations

## Installation

The module is published in the PSGallery, so if you have PowerShell 5 or newer can be installed by running:

```powershell
Install-Module AzureCAF
```
